# Ensemble Homebrew tap

```bash
brew install ensemblework/tap/ensemble
ensemble login
```

`Formula/ensemble.rb` is updated automatically by the `cli-release` workflow in [ensemblework/ensemble](https://github.com/ensemblework/ensemble) for every `cli-v*` release. Do not edit it by hand.
